# 画面設計

Androidスマートフォンの縦画面を主対象にする。文字と数字を優先し、システムフォント、Material 3の明暗テーマ、控えめな1色のアクセントを使う。配色とアプリ名は仮案。

## 1. ナビゲーション

下部タブは「履歴」「集計」「予算」「目標」の4つ。起動時は今月の履歴。上部の設定ボタンからバックアップ画面へ進む。「＋記録」を主要画面から1タップで開ける位置に置く。

| 画面 | 表示 | 主な操作 |
|---|---|---|
| 履歴 | 月選択、月の収入・支出・収支、日別取引、日別の収入・支出 | 月移動、追加、取引を開いて編集・削除 |
| 入力・編集 | 種別、金額、カテゴリ、日付、任意メモ | 保存、キャンセル、編集時の削除 |
| 集計 | 月の支出合計、カテゴリ別横棒、金額、割合 | 月移動、カテゴリ選択でその月・カテゴリの履歴へ |
| 予算 | 月全体とカテゴリ別の予算・実績・残額 | 予算設定、未設定に戻す、前月からコピー |
| 目標 | 目標名、目標額、現在の積立額、進捗 | 追加、編集、削除 |
| 設定・バックアップ | 保存方針、書出し、復元、アプリ版 | システムファイル選択、確認 |

履歴・集計・予算の選択月は共有する。初回は端末の今日の月。別画面から戻っても月を維持する。カテゴリ絞り込みは履歴に解除可能な表示を付け、月の合計とは区別して「絞り込み結果○円」を示す。

## 2. 入力画面

表示順は、支出/収入の切替 → 金額 → カテゴリのチップ → 日付 → 任意メモ → 保存。

新規では金額にフォーカスを置き、数字キーボードを表示する。金額欄に前の金額を残さない。カテゴリが記憶済みなら「金額入力→保存」で完了できる。カテゴリ初回未選択時は選択を促す。日付は今日を表示しタップで変更する。

保存成功後は元の画面へ戻り、一覧・グラフ・予算が更新される。選択中の月と保存した取引の月が違う場合は「○月○日に保存しました」と表示し、その月へ移動できる操作を添える。

戻る操作で未保存の変更があれば破棄確認。保存中は入力・戻る・再保存を無効にする。保存失敗時は値を保持し、再試行可能にする。キーボード表示中も保存ボタンに到達できるようスクロールとIMEインセットを扱う。

## 3. 履歴と集計

履歴1行にはカテゴリ、内容（あれば）、金額、収入/支出の区別を表示。日付はグループ見出し。金額は右揃えで桁区切りを使う。収入には「収入」または＋、支出には「支出」または−を付け、色に頼らない。

集計は支出額が大きい順。横棒の長さは最大カテゴリ額に対する比率、併記する割合は月の支出全体に対する比率とする。凡例として「棒はカテゴリ間の比較、％は支出全体に占める割合」を補足できる。実績0円のカテゴリは通常は省略。支出0円では空状態を表示する。

## 4. 予算画面

月全体を上段、カテゴリごとを下段に表示する。「残り予算」は使える現金残高ではなく設定した上限との差であると、初回説明で伝える。

編集フォームでは空欄＝未設定、0＝0円上限。保存時に明確に表示して取り違えを防ぐ。前月コピーの確認には対象月と置き換える設定件数を示す。

## 5. 目標画面

積立額の入力ラベルは「現在の積立額」。初回に「収支とは別に、貯めた額を入力します」と説明する。目標到達後も金額更新可能。目標の削除確認には名称を表示する。

## 6. バックアップ画面

- 書き出し：JSONに含む内容、暗号化なし、保存先を自分で選べる旨を短く表示。
- 復元：ファイル選択→検証→作成日時とデータ件数の表示→置き換え確認→処理→完了。
- 置き換え前には現在データの書き出しボタンも用意。自動で未選択の場所へ外部保存しない。
- 置き換え確認文は「現在の記録・予算・目標を、このファイルの内容に置き換えます」。空バックアップの場合は全件0になることを強調する。
- 処理中は全画面の編集を停止し、待機を表示。成功前に完了表示や遷移をしない。

## 7. 共通状態とアクセシビリティ

| 状態 | 表示・動作 |
|---|---|
| 初回・空 | 「まだ記録がありません」と追加ボタン。架空の支出を実データとして入れない |
| 読込中 | 画面骨格と進行表示。入力可能な部分だけ操作可能にする |
| DB・保存エラー | 分かる言葉で失敗を示し再試行。勝手に0円や空データへ置換しない |
| ファイル選択取消 | 元画面へ戻る。データ変更なし |
| 検証エラー | 問題の種類と修正可能な箇所を示す。ファイル内容全文をログへ出さない |
| 予算超過 | 超過額を文字でも表示 |

TalkBack、文字サイズ200%、横画面、キーボード表示時の確認を行う。主要なタップ領域は48dp以上。読み上げ順は画面の意味の順にする。
