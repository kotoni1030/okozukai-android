# 決定事項と初期仕様案

仕様版1.0／2026-11-17。確定した希望と、実装のために補った判断を区別します。

## 資料と新しい指示が矛盾した場合

過去の資料と現在のユーザー指示に齟齬が見つかった場合は、実装または資料更新の前に、齟齬の内容・それぞれの記載・影響範囲を利用者へ比較して示し、採用する内容を確認する。現在の指示が明確に優先する内容を示す場合のみ、その内容に合わせて関連資料を更新する。

## ユーザーが確定した事項

| 項目 | 決定 |
|---|---|
| 目的 | 何にどれくらい使ったかを明確にする |
| 利用者 | 当面自分用、将来は公開予定 |
| 対象 | Android用。相談後、Kotlinで開発すると決定 |
| 経験 | Webの知識あり。Kotlin・Flutterは未経験 |
| 記録 | 支出、内容、収入、予算、貯金目標 |
| 入力 | 手入力で開始。手間を減らし、後から改善 |
| 支出項目 | 金額・カテゴリ必須、日付は今日を初期値、内容は任意 |
| 収入項目 | 金額・日付・種類・任意のメモ |
| 表示 | いついくら使ったかが分かる履歴、カテゴリ別グラフ |
| 予算 | 月全体とカテゴリ別。毎月1日〜末日 |
| 保存 | 基本ローカル。軽快さを重視 |
| 復旧 | 初期版からバックアップを実装 |
| 見た目 | シンプル |
| 貯金目標方式 | おまかせ |

## 実装を進めるための初期仕様案

以下はユーザーの逐語的な指定ではなく、会話から補った案です。実装を開始できます。変更時は関連資料も更新します。

| 項目 | 採用案と理由 |
|---|---|
| UIと保存 | ComposeとRoom。Androidの標準的な仕組みで構成を理解しやすくする |
| アプリ名 | 仮称「お小遣い帳」。公開名称は後で決定 |
| 言語・通貨 | 日本語・日本円のみ。小数なし |
| 対応下限 | Android 8.0 / API 26を仮採用。実機OSと依存関係をP0で確認し調整 |
| カテゴリ | 初期版は固定10種類（支出7、収入3）。「後で変更」の意味が未確定なので編集UIは次版候補。固定IDを使い後から名称変更・追加・非表示化を可能にする |
| 貯金 | 複数目標。目標名・目標額・現在の積立額を手入力。収支と連動しない |
| 予算更新 | 月ごとに保存。繰越なし。前月コピーは明示操作で実施 |
| グラフ | 選択月のカテゴリ別横棒グラフ。数値と比較しやすく大きな依存を増やさない |
| 履歴 | 日付別一覧。カレンダー画面は初期版に含めない |
| バックアップ | バージョン付きJSON。復元は全体置き換え。マージは行わない |
| 保存の運用 | 手動バックアップ中心。OSの自動クラウドバックアップと端末移行の除外設定を実装・検証 |
| 費用・サービス | 初期版は有料APIやサーバーを使用しない。ストア公開関連の費用は公開時点で確認 |

## 未確認だが資料作成・基本実装を妨げない事項

- Android実機の有無、機種、OS、メモリ：P0で確認。未確認のまま実機確認済みとしない。
- 開発PCのAndroid Studio・JDK・SDKの導入状態：P0で調査。
- カテゴリをどう変えたいか：初期値をコードとデータの両面で変更容易にする。
- 公開名、applicationId、配布先、署名：本格的に利用する初回APKの前にapplicationIdと署名の継続方針を確定し、一般公開の詳細は後続作業にする。
- iPhone版：要望として確定していない。初期版に含めない。

## 範囲に含めない機能

初期版ではレシートOCR、銀行・カード連携、口座別残高、クラウド同期、ログイン、家族共有、定期取引、自動振替、外貨、広告、課金、AIによる自動分類は実装しません。これらは将来案であり、完成条件に含めません。

## 実装時の可逆的な選択（2026-11-17）

- 開発用applicationIdは `jp.local.okozukai.dev`。日常利用・公開用のIDと署名は未確定。
- 現時点の画面数ではタブと入力画面の状態だけで遷移を表せるため、Navigation Composeはまだ導入せず、ViewModelと保存可能なUI状態で制御する。画面が増えた段階で再検討する。
- Roomのv1全テーブルを初回から作成し、schema JSONを保存。変更する場合はv2以降の明示移行とテストを追加する。
- 画面再生成で編集ID・入力を保存し、復元成功時にはresetキーとRepositoryの世代番号で古いフォームを破棄する。
- Gitは親フォルダから独立した本プロジェクト専用の管理を作成。ユーザー指定のGitHubリポジトリへ区切りごとにpushする。
